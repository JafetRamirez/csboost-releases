# CSBoost — downloads

Otimizador gratuito de Windows para Counter-Strike 2.

**Baixe a versão mais recente em [Releases](https://github.com/JafetRamirez/csboost-releases/releases/latest)** e rode o `CSBoost_x.y.z_x64-setup.exe`.

- Windows 10 e 11 (64 bits). O app pede permissão de administrador ao abrir.
- Todo ajuste pode ser desfeito pela tela Histórico.
- Não injeta nada no jogo e não mexe em arquivos do CS2 — compatível com o Trusted Mode da Valve.
- Depois de instalado, o CSBoost se atualiza sozinho a partir deste repositório.

Enquanto o instalador não tiver assinatura digital, o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**.
