TERMOS DE USO DO CSBOOST
Versão 0.4 — outubro de 2026

Leia com atenção antes de instalar.

1. O que o CSBoost faz
O CSBoost é um programa para Windows 10 e 11 que analisa o computador e aplica ajustes de configuração do sistema (registro do Windows, plano de energia, taxa de atualização do monitor e arquivos de configuração do Counter-Strike 2) para melhorar o desempenho em jogos.

2. Permissão de administrador
Para alterar configurações do sistema, o CSBoost pede permissão de administrador sempre que é aberto.

3. Alterações reversíveis
Antes de qualquer alteração, o CSBoost guarda o valor anterior e, quando o Windows permite, cria um ponto de restauração do sistema. Todas as alterações feitas pelo programa podem ser desfeitas pela tela Histórico. Ao desinstalar, o CSBoost pergunta se você quer desfazer todos os ajustes antes de sair.

4. Jogos e sistemas anti-cheat
O CSBoost não injeta código, não lê nem altera a memória de jogos e não modifica arquivos dos jogos — apenas arquivos de configuração do usuário. Ainda assim, cada desenvolvedor de jogo define as próprias regras, e o usuário é responsável por respeitá-las.

5. Resultados
O ganho de desempenho varia conforme o hardware, os drivers e o estado do sistema. Não garantimos aumento específico de FPS ou redução de latência.

6. Isenção de garantia
O CSBoost é fornecido "como está". Na máxima extensão permitida pela lei, não nos responsabilizamos por perdas de dados, falhas de hardware ou de software decorrentes do uso do programa. Mantenha backups dos seus arquivos importantes.

7. Privacidade
O CSBoost não coleta nem envia dados pessoais ou informações do seu computador. As informações de diagnóstico ficam apenas no seu computador. A única conexão automática é a consulta de novas versões no GitHub (github.com), que não envia dados seus.

8. Licença e código-fonte
O CSBoost é software livre, distribuído sob a Licença Pública Geral GNU, versão 3 ou posterior (GPL-3.0-or-later). O código-fonte está em https://github.com/JafetRamirez/csboost-releases. Componentes de terceiros mantêm as próprias licenças (veja THIRD_PARTY_NOTICES.md no repositório).

CSBoost is a program for Windows 10 and 11 that analyzes the computer and applies system configuration changes (Windows registry, power plan, monitor refresh rate and Counter-Strike 2 configuration files) to improve gaming performance.

To change system settings, CSBoost asks for administrator rights every time it opens.

Before any change, CSBoost saves the previous value and, when Windows allows it, creates a system restore point. Every change made by the program can be undone from the History screen. When uninstalling, CSBoost asks whether you want to undo all changes before leaving.
